## V2 Short

This new 37-second vertical edit opens with the make.fun parachute robot in a flashing-police getaway animation, then cuts into the street, police, and robbery passage from Rockstar Games’ *Grand Theft Auto VI Trailer 2* (about 0:46–1:12). It closes on a high-contrast pitch card: make cool clips with AI, earn money on make.fun, and visit the GTA 6 clipping bounty.

The upload title and complete description are in [clip-meta.txt](clip-meta.txt). The final YouTube address will be recorded in `VIDEO.json` after upload.

- Play code: `makefun-cavern-kite-reef`
- Bounty: [make.fun/bounty/gta6-clipper-01](https://make.fun/bounty/gta6-clipper-01)

`main.ts` copies the root `VIDEO.json` into the make.fun runner’s output directory.
